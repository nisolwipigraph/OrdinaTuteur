# OrdinaTuteur

OrdinaTuteur — помощник для Windows. Напиши, что хочешь сделать, и программа
будет предлагать по одному следующему шагу. Чтобы дать подходящую подсказку,
она делает снимок экрана и отправляет его вместе с задачей в LimitDeck AI.

## Как запустить

1. Установи .NET 10 SDK и Python 3.
2. Установи Pillow — библиотеку Python для работы со снимками:

   ```powershell
   py -3 -m pip install -r requirements.txt
   ```

3. Укажи свой ключ LimitDeck AI в `AIKey.py`. Не публикуй этот файл и не
   отправляй его другим людям.
4. Дважды щёлкни `start.vbs`. Этот сценарий соберёт приложение, если исходники
   новее готовой программы, и запустит её.

Можно собрать приложение вручную:

```powershell
dotnet build -p:Platform=x64
```

После сборки приложение находится по пути
`bin\x64\Debug\net10.0-windows10.0.19041.0\win-x64\OrdinaTuteur.exe`.

Обычно программа запускает Python командой `py -3`. Если Python Launcher не
установлен, задай переменную `ORDINATUTEUR_PYTHON` с путём к `python.exe`.
Например: `C:\Python313\python.exe`. Консольное окно Python не открывается.

## Как работает программа

1. Ты вводишь задачу и нажимаешь «Отправить» или клавишу Enter.
2. Приложение временно прячет окно и просит Python сделать снимок экрана.
3. Приложение отправляет Python задачу, снимок и историю подтверждённых шагов.
4. Python добавляет сведения о версии Windows и приложениях по умолчанию, затем
   отправляет всё в LimitDeck AI.
5. Python передаёт ответ приложению по частям, чтобы текст появлялся постепенно.
6. Кнопка «Дальше» подтверждает шаг и начинает следующий. Кнопка со стрелкой
   просит ИИ перепроверить последний ответ с тем же снимком.

Программа читает из настроек Windows только версию системы и приложения по
умолчанию для браузера, почты и PDF. Полный список установленных программ она
не собирает.

## Какие файлы за что отвечают

- `MainWindow.xaml` — описание внешнего вида окна: область чата, поле ввода и
  кнопка отправки.
- `MainWindow.xaml.cs` — поведение окна: обработка кнопок, история задачи,
  отображение ответа и связь с Python.
- `brain.py` — Python-часть: снимок экрана, сведения о Windows, запрос к ИИ и
  передача ответа в приложение.
- `AIKey.py` — настройка с секретным ключом доступа. Не добавляй этот файл в
  публичный репозиторий.
- `requirements.txt` — список библиотек Python. Сейчас в нём только Pillow.
- `App.xaml` — общие ресурсы и стили элементов WinUI.
- `App.xaml.cs` — запускает главное окно приложения.
- `OrdinaTuteur.csproj` — настройки .NET-сборки и список нужных библиотек.
- `app.manifest` — сообщает Windows о совместимости и настройках масштаба.
- `start.vbs` — проверяет, нужна ли сборка, собирает приложение и запускает его.
- `README.md` — эта инструкция и краткое описание проекта.

Папки `bin` и `obj` создаются при сборке. В `bin` лежит готовая программа, а
`obj` содержит временные файлы для сборки. Обычно вручную менять их не нужно.

## Простые объяснения терминов

- **C#** управляет окном и кнопками. **Python** делает снимок и общается с ИИ.
- **XAML** — текстовое описание того, как расположены элементы окна.
- **JSON** — текстовый способ упаковать данные в поля и значения. Например,
  поле `question` содержит задачу, а `image` — снимок экрана.
- **История** — список прошлых сообщений и шагов текущей задачи. Она хранится
  только в памяти, пока приложение открыто.
- **`async` и `await`** позволяют ждать ответа, не замораживая окно.
- **Потоковый ответ** приходит маленькими частями. Программа показывает их сразу,
  не дожидаясь всего ответа.
- **Снимок в формате Base64** — изображение, записанное как текст, чтобы его
  можно было положить в JSON и отправить по сети.
- **Реестр Windows** — системное хранилище настроек. Программа читает из него
  только выбранные приложения по умолчанию.

## Данные и приватность

Для ответа в LimitDeck AI отправляются текст задачи, снимок экрана, история
текущей задачи и короткие сведения о Windows. Снимок делается перед каждым
новым шагом. Переделка ответа использует снимок, сделанный для этого шага.
Не отправляй экран с личной или конфиденциальной информацией.

Ключ доступа находится в `AIKey.py`. Считай его паролем: не публикуй и не
пересылай его. История задач не сохраняется на диск.
